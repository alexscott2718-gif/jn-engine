## Status Key
- ✅ Verified — compared to XP original, looks correct
- ⚠️ Needs review — visual inspection / XP ground truth pending
- ❌ Issue — known problem (e.g., UV flip, missing data, mismatch)

## Template for Annotation
When reviewing a texture, fill in:
- **Status**: one of ✅/⚠️/❌
- **XP Notes**: What it looks like in the original game, any quirks
- **Issues / Fixes**: What changed, what needs to change, or what's confirmed correct
