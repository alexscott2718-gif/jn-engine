## Workflow
1. Open the relevant gallery HTML (e.g., `gallery-sprites.html`)
2. Visually inspect assets, optionally compare to XP original via VNC
3. Return here and fill in status, XP notes, and issues/fixes
4. Reference filled entries when making engine changes
