Goal

Generate a testable cutscene catalog from shipped .gam data and make those cutscenes playable on demand from the public web deploy via a button/menu. This is for QA: no campaign progression required, no normal auto-play, and no disruption to the faithfulness audit.

Implementation Phases

Phase 1 - Catalog DONE

tools/build_cutscene_catalog.py parses every .gam and emits review/web catalogs. Each 3MCA row carries its indexed targets, camera types, look offsets, and SoundDatabase/SoundIndexN audio handles.

{
  "level1b": [
    {
      "tag": "neutron1a",
      "type": "3MCA",
      "shots": ["LABEXP1", "LABEXP2", "WATCHGODDARD"],
      "targets": ["JIM1", "goddardpat2", "C3DGODDARD"],
      "goddard_related": true
    }
  ]
}

Phase 2 - Runtime API DONE

behavior_cutscene.c now supports web-callable indexed 3MCA playback:

  • cutscene_count_web(), cutscene_request_web(index), cutscene_active_web(), and cutscene_stop_web().
  • Each cutscene step starts its authored SoundDatabase/SoundIndexN audio handle.
  • Keep direct level loads audit-safe: cutscenes play only when explicitly requested.

Phase 3 - Web UI DONE

web/shell.html has a compact Cutscene selector plus Play/Stop. It works without Campaign mode and returns focus to the canvas after clicks.

Phase 4 - Fidelity

Next work: tune exact camera modes against original capture, apply target animations, honor player-control locks, implement FaceObject, and continue tracking Goddard texture/mapping separately.
